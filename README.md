## Turkey Run: Kabur dari Peternakan

Thanksgiving datang dan petani sudah mengasah pisau. Kamu seekor kalkun yang
harus kabur dari peternakan menuju hutan — melewati kandang, ladang jagung,
dan dapur — sebelum jadi makan malam.

Lompati pagar dan jerami, hindari anjing dan pisau jatuh, jangan sampai
terperosok ke lumpur, dan kumpulkan jagung, bulu, dan labu. Petani mengejarmu
dari belakang: makin lama kamu lambat, makin dekat dia. Dash dan jagung
membuatnya menjauh. Tiga stage, tiga nyawa, satu hutan untuk diselamatkan.

## Cara main

- **Gerak:** panah / WASD (atau tombol di layar)
- **Lompat:** SPASI — lompat pagar, jerami, dan oven
- **Dash:** SHIFT / X — lari cepat, petani menjauh
- **Mulai / ulang:** ENTER · **Cara main:** H · **Suara:** M

## Run it

Serve the `game/` folder with any static server and open `game/index.html`
in a desktop browser. No network, no build step, no libraries — all art is
drawn in code and all sound is made with WebAudio.

```sh
npx serve game
```

Skor terbaik dan level terjauh tersimpan di browser (localStorage).
